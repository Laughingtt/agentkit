## 一句话简介

Part 1 讲了 LLM 怎么训练出来，Part 2 讲了这一路怎么走过来、Agent 的积木有哪些。Part 3 回答"这些积木怎么装起来"：感知、记忆、规划、行动四件套如何在运行时协作；ReAct、Reflexion、Plan-and-Execute 三种范式各自在什么情况下好用；以及为什么真实的 Agent 系统往往不是"一个大模型"，而是几类部件各司其职。
