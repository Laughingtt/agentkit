## 2.1 神经元与多层感知机

**人工神经元**是神经网络的基本单元，它做的事情非常朴素：把若干输入按权重加和、加上偏置、再过一个非线性函数。类比成一个**加权投票器**——每个输入按重要性打分，最后汇总成单一输出。

先看一个能拿计算器按出来的例子。假设有三个输入 $x_1, x_2, x_3$，它们的权重（每个输入的话语权）分别是 $w_1 = 2$、$w_2 = 0.5$、$w_3 = -1$，偏置（不管输入如何都要加的那个固定分）$b = 3$。来了一组输入 $(x_1, x_2, x_3) = (4, 2, 5)$，那么：

$$2 \times 4 + 0.5 \times 2 + (-1) \times 5 + 3 = 8 + 1 - 5 + 3 = 7$$

这一步叫**加权和**。注意权重可以是负数——意思是这个输入越大，反而越该被扣分。接下来还要过一道**激活函数**：把刚才的 7 变成这个神经元的最终输出。

于是通用写法是 $y = \sigma(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b)$。三个符号各是什么：**$x$ 是输入**（给它的数据）、**$w$ 是权重**（每个输入的话语权）、**$b$ 是偏置**（固定加分项）、**$\sigma$ 是激活函数**（下一步 2.2 讲）。

把多个神经元排成一层、把多层堆叠起来，就得到**多层感知机（Multi-Layer Perceptron, MLP）**。典型的 MLP 包含输入层、若干隐藏层和输出层；每一层的输出作为下一层的输入，层层"加工"。我们这本书记号上把输入维数为 1、两个 32 维隐藏层、输出维数为 1 的网络记为 1 → 32 → 32 → 1。本章配套代码 `train_mlp.py` 用的就是这个结构。

那为什么一定要在层与层之间插入非线性激活函数？因为如果只有线性变换，多层堆叠等价于一个更大的线性变换——模型永远只能表达直线或平面，拟合能力非常有限。引入非线性后，整个网络才变成一个"通用函数逼近器"，理论上可以拟合任意复杂的连续函数。**这也是为什么一个没有激活函数、只有线性层的"深度网络"，本质上和单层线性回归没有区别。**

## 2.2 激活函数

激活函数负责给神经网络"加非线性"。接上 2.1 那个例子：加权和算出来是 7，激活函数要干的事就是**再拿 7 去算一个数**出来。

**ReLU（Rectified Linear Unit）** 是最常见的激活函数，规则简单到可以一句话说完：**$f(x) = \max(0, x)$——正数原样输出、负数归零。**

拿刚才的例子：加权和是 7（正数），ReLU 原样吐出 7；假如权重换成 $w_1 = -2$，加权和变成 $7 - 16 = -9$，ReLU 就把它压成 0。**你可以把它想成一个只认"正向推动"的开关：往上推的照单全收，往下拉的直接归零。** 它由 Nair 和 Hinton 在 2010 年 ICML 论文中正式推广（参见本章参考）。ReLU 最大的优点是简洁、计算快，而且在正区间梯度恒为 1，有效缓解了深层网络中常见的梯度消失问题，是 CNN 和 MLP 的默认选择。它的缺点是"死神经元"——一旦某个神经元输出落到负区间且梯度为 0，它就再也不会更新。

**GELU（Gaussian Error Linear Unit）** 是 Transformer 时代的默认激活，定义为 $f(x) = x \cdot \Phi(x)$，其中 $\Phi$ 是标准正态分布的累积分布函数。（正态分布就是那条中间高两头低的钟形曲线；$\Phi(x)$ 的意思是"钟形曲线在 $x$ 左边的面积占比"，所以 $\Phi(0) = 0.5$、越大的数越接近 1。）直观上，GELU 比 ReLU 更平滑——**ReLU 在 0 附近是"一刀切"（从 0 突然跳到原值），GELU 是"慢慢过渡"（越接近 0 打得越轻，但不完全归零）**，给所有输入都留一点点非零梯度，训练更稳定。GPT、BERT 等主流模型都用 GELU。

**Softmax** 跟前面两个不一样，它专门用在多分类任务的输出层。它把一组实数（logits）转换成概率分布：每个值先指数化，再除以所有指数之和，保证输出和为 1、每个值在 (0, 1) 之间。这样模型最后一层的输出就能直接解读为"属于每一类的概率"。后面 Ch4 会看到，LLM 在每个位置上预测下一个 token，本质上就是一个词表大小（几万到十几万）的多分类任务，输出层用的就是 Softmax。

## 2.3 反向传播的直觉

**反向传播（Backpropagation）** 是训练神经网络的核心算法。我们不需要手推公式，但必须抓住它的直觉。

训练的目标：调整每一层的权重 $W$ 和偏置 $b$，让损失函数的值尽可能小。损失函数衡量"模型预测"与"真实答案"之间的差距。函数告诉我们"在当前权重下，预测错得有多离谱"，但没直接告诉我们"权重该怎么改"。

反向传播回答的就是"权重该怎么改"这个问题。它的核心思想是**链式法则**。

> **链式法则是什么？** 如果 $y$ 是由 $a$ 算出来的、$a$ 又是由 $b$ 算出来的，那么"$b$ 动一点点会让 $y$ 变多少"等于"**$b$ 动一点点会让 $a$ 变多少**"乘以"**$a$ 动一点点会让 $y$ 变多少**"。**沿途每一小段的放大倍数相乘，就是全程的放大倍数。** 一句话：中间插了多少道工序都不影响，只要把每道的倍数乘起来。
>
> 神经网络正好是"一环套一环"，所以这个定理在这里特别好用。

那条"变化了多少倍数"在数学上叫**梯度**（gradient）。换个说法，**梯度像水流一样从损失端往输入端流回每一层**——每一层根据流到本层的梯度，知道"自己该往哪个方向调、幅度多大"。

> 下面图里那个符号 **∂** 读作"偏"，$\frac{\partial L}{\partial \hat{y}}$ 念作"**损失 $L$ 对预测值 $\hat{y}$ 的变化率**"——预测值动 1，损失跟着动多少。它是写"变化率"的一种记号，你只要把它读成上面那句话就够了，不必会算。

⚠️ **上一段最后那句"知道自己该往哪个方向调"还差半句，这里补上——这半句是 2.5 那条式子里那个负号的来处。** 梯度指的方向，是**损失涨得最快**的那个方向，**不是"变好"的方向**。我们要的是损失变小，所以只能朝它的**反方向**走。

**类比。** 下山。你站在坡上，能一眼看出哪边最陡；可你是朝**上坡的反方向**迈步的，不是朝最陡的那边。"最陡的方向"告诉你往哪儿躲开，"反方向"才告诉你往哪儿走。

一句话记住：**梯度指上坡，我们走下坡——式子里那个减号就是这么来的**，它不是一条约定，是"我要下山"这件事本身。

这句话光看容易糊，摊到 2.1 那个 `1 → 32 → 32 → 1` 的小网络上就清楚了。同一个输入走两趟，方向相反：

```text
        前向：算出预测，损失随之确定
  x ──▶ [层1] ──▶ [层2] ──▶ 预测 ŷ ──▶ 损失 L
  1维              32维                1维

        反向：L 的梯度一层层往回传
  ∂L/∂ŷ ──▶ ∂L/∂[层2] ──▶ ∂L/∂[层1] ──▶ ∂L/∂W₁
     1            32              32
```

**两趟的方向相反，但数据形状始终对得上**——损失是 1 维的，梯度就以 1 维的样子回到输出端；流进层 2 的梯度被撑成 32 维（因为层 2 有 32 个神经元，每个都要知道自己该调多少）；再流进层 1 时又被撑成 32 维。这个"撑开"不是额外计算，是链式法则里乘进去的那个上游梯度天然带来的。

所以训练一轮其实就五件事，顺序不能换（这就是本章配套 `train_mlp.py` 里那五行）：

```python
pred = model(x)              # 1. 前向：走一遍，顺便把计算图记下来
loss = loss_fn(pred, y)      # 2. 算损失，一个标量
optimizer.zero_grad()        # 3. 清空上一轮攒下的梯度
loss.backward()              # 4. 反向：上面的那趟梯度流回来，落到每个 .grad 上
optimizer.step()             # 5. 更新：每个参数按自己的梯度挪一小步
```

第 3 步为什么不能省？因为 PyTorch 的梯度是**累加**的——`backward()` 是往 `.grad` 上加，不是覆盖。不清零的话，第二轮的梯度就是"第一轮的错 + 第二轮的错"，越积越偏。**这是新手写训练脚本最常踩的一个坑，而且它不报错，只是效果变差。**

实际工程里没人手算这些梯度。PyTorch 用**自动微分（autograd）**机制——第 1 步走过的地方被记成一张计算图，第 4 步的 `backward()` 就是**照着这张图倒着走一遍**，自动算出所有参数的梯度；第 5 步的优化器再根据这些梯度更新参数。整套过程对用户几乎是透明的，**你只写前向，剩下四步是库替你做的**。

## 2.4 损失函数

损失函数（Loss Function）量化模型预测与真实答案的差距，是训练的"指挥棒"。任务不同，指挥棒也得换。

**均方误差（Mean Squared Error, MSE）** 用于回归任务，定义为预测值与真实值之差的平方的平均：$L = \frac{1}{N} \sum (y_i - \hat{y}_i)^2$。它对大误差的惩罚更重（平方放大了差距），训练出来的模型倾向于平滑预测。它不要求输出是概率，适合"预测房价""预测温度"这种连续值输出。本章配套代码 `train_mlp.py` 就用 MSE 拟合正弦曲线。

**交叉熵损失（Cross-Entropy Loss）** 用于分类任务。它衡量两个概率分布之间的"距离"——预测分布越接近真实分布（one-hot 标签），损失越小。配合 Softmax 输出层时，公式有个非常简洁的等价形式：$L = -\log(\hat{y}_{\text{correct class}})$，即"正确答案对应的预测概率取负对数"。如果模型对正确类别给出 0.99 的概率，损失约 0.01；如果只给 0.1，损失高达 2.3——逼迫模型在正确选项上"加把劲"。

简单记法：**连续值用 MSE，离散分类用交叉熵**。LLM 的语言模型头也是分类——从词表里挑下一个 token，所以训练时用的就是交叉熵（具体细节见 Ch4）。

## 2.5 优化器演进

**优化器（Optimizer）** 负责根据梯度更新参数。三代主流优化器值得了解。

**SGD（随机梯度下降）** 是最朴素的形式：$W \leftarrow W - \eta \cdot \nabla L$。学习率 $\eta$ 是唯一超参，控制"**朝反方向**、每一步迈多远"。SGD 思路简单、稳定性好，但所有参数共用同一个学习率，对稀疏梯度或不同尺度的参数不太友好。

**Adam（Adaptive Moment Estimation）** 是 2014 年 Kingma 和 Ba 提出的优化器，2015 年发表于 ICLR（参见本章参考）。它为**每个参数维护自适应的学习率**——同一个网络里，某些参数该迈大步、某些该迈小步，Adam 让它们各走各的。

怎么做到的？它同时记两本账：

- **第一本账（一阶矩）**：把过去几步的梯度**平均一下**再当步长用。梯度忽大忽小时，平均值比单次值稳，等于给这一步加了"惯性"，不会因为一次异常就冲过头。
- **第二本账（二阶矩）**：把过去几步的梯度**平方后再平均**，用来估计"这个参数最近的变化幅度有多大"。

两本账一除，就得到"这一步该迈多大"（近期的梯度大小除以近期的梯度平方大小），**学习率于是不用人调了**——这就是"自适应"的含义。Adam 收敛快、调参省事，是深度学习事实上的默认优化器。

**AdamW（Adam with decoupled Weight Decay）** 由 Loshchilov 和 Hutter 在 2019 年提出。先说清楚它多干的那件事：**AdamW 比 Adam 多了一项"把权重往 0 拉"的惩罚**（叫**权重衰减**，白话说就是"别让参数变得太大"，完整机制 2.6 讲）。Adam 把这项惩罚混在梯度里一起算，AdamW 把它"解耦"出来直接作用在参数上：

$$W \leftarrow W - \eta \cdot \nabla L - \eta \cdot \lambda W$$

三部分各是什么：$\eta$ 是学习率（迈多大步）、$\nabla L$ 是梯度（往哪个方向，见 2.3）、$\lambda$ 是惩罚的力度，最后那个 $-\eta\lambda W$ 就是"每走一步，按同样的步长把权重往 0 收一点点"。**"解耦"的关键在于这个 $\lambda W$ 不参与 Adam 那套自适应缩放**——老写法里它是被 Adam 的自适应除数一起缩放的，等于力度被悄悄改了；AdamW 让它按原力度直接生效。这一改动让训练更稳定、泛化更好，是训练现代 Transformer 的标配，本书后续章节默认使用 AdamW。

## 2.6 正则化

正则化（Regularization）的目的只有一个：防止模型在训练集上学得太好、在测试集上却表现糟糕（**过拟合**）。两个最常用的工具是 Dropout 和 Weight Decay。

**Dropout（随机失活）** 由 Srivastava 等人在 JMLR 2014 正式系统化（参见本章参考）。做法很简单：训练时每一轮前向传播，对每个神经元以概率 $p$（常见 0.5）随机"关闭"——输出置零；测试时则使用全部神经元并按 $p$ 缩放权重。直觉是：每次前向传播都在用一个"瘦了"的子网络，迫使模型不能依赖任何单个神经元。Dropout 在全连接层和 RNN 里特别常用，现代 Transformer 因为有 LayerNorm 和大量数据，Dropout 用得反而少。

**Weight Decay（权重衰减）** 是另一类正则：给损失函数加一个 $\lambda \|W\|^2$ 惩罚项，等价于让权重在每步更新里都略微往 0 收缩。AdamW 里的"W"就是这套机制的现代实现。

简单记法：**Dropout 管结构（神经元要不要参与），Weight Decay 管参数（参数不要太大）**。

## 2.7 归一化

归一化（Normalization）是深度学习里另一类不可或缺的工具，目的都是让激活值的分布更稳定，从而加速收敛、提高泛化。

**先说为什么要归一化。** 2.1 说过，一层层传下去，每层的数字会越来越大或越来越小。如果第 30 层收到的数字是第 1 层的十万倍，那第 30 层稍微调一点参数，输出就天翻地覆——**学习率没法同时适配所有层**，调大了前面炸、调小了后面不动。归一化就是**每过一层就把它拉回"平均 0、大小适中"的尺度**，相当于给每一层都配一把独立的尺子。

**Batch Normalization（批归一化, BN）** 由 Ioffe 和 Szegedy 在 2015 年提出（参见本章参考）。做法是：对每个特征通道，在一小批数据（**mini-batch**，训练时一次性喂进去的几十到几百个样本）内部计算均值和方差，把激活值标准化到均值为 0、方差为 1，再乘一个可学习的 $\gamma$、加一个可学习的 $\beta$（两个数字，训练时自己学，等于"标准化完允许我再调一下"）。BN 的好处是允许更大的学习率、对初始化不敏感、还自带正则效果。**BN 沿"batch 维度"归一化**——它要凑齐一小批样本才算得出平均，所以对 batch size 敏感，在 RNN 和小 batch 场景下不太友好。它是 CNN 时代的标配（ResNet 几乎所有卷积层后都接 BN）。

**Layer Normalization（层归一化, LN）** 由 Ba、Kiros 和 Hinton 在 2016 年提出。它和 BN 的关键区别是**沿"特征维度"归一化**——对单个样本内的所有特征计算均值和方差，独立于 batch。LN 不受 batch size 影响，天然适合序列模型，所以成为 Transformer 的标配（每一层 Attention 和 FFN 之后都接一个 LN）。这也是为什么 GPT、BERT、LLaMA 等所有主流 LLM 都用 LN 而不是 BN。

| 维度 | BatchNorm | LayerNorm |
|---|---|---|
| 归一化范围 | 跨样本（同一通道） | 跨特征（同一样本） |
| 依赖 batch size | 是 | 否 |
| 主要应用 | CNN | Transformer / RNN |

归一化层放在子层（注意力或 FFN 这样的**一整块**计算）的前面还是后面，位置对训练稳定性影响很大。放在前面叫 **pre-norm**，放在后面叫 **post-norm**——现代 LLM 几乎都用 pre-norm，2017 年那篇原始 Transformer 用的是 post-norm。注意这里的"前后"是相对于**整个子层**说的，不是层内的某一步（这一点很容易记岔，Ch3 §3.6 会给出块子长什么样）。

## 2.8 一个最小的 PyTorch 训练示例

光讲概念不够直观，我们用一个最小可运行的例子把上面所有零件串起来。完整代码见 `code/part-1/train_mlp.py`。

**模型定义**：MLP 类继承自 `nn.Module`，由 `nn.Sequential` 串起 3 个线性层和 2 个 ReLU——结构就是 2.1 节说的 1 → 32 → 32 → 1。

**数据准备**：用 `torch.linspace` 在 $[-2\pi, 2\pi]$ 上取 200 个点，目标是 `y = sin(x)`。这是一个非线性函数，没有激活函数的纯线性模型绝对拟合不了，正好用来验证 MLP 的非线性能力。

**训练三件套**：损失函数用 `nn.MSELoss`（回归问题）；优化器用 `optim.Adam`，学习率 1e-2，对这个小网络正合适；训练循环 1000 步，每步就是 2.3 讲的那五步——前向算 `loss`、清梯度、`loss.backward()` 反向传播、`optimizer.step()` 更新参数。这是 PyTorch 训练的"标准动作"，几乎所有训练脚本都长这样。

**收敛判断**：循环结束后再算一次 `final_loss`，并用 `assert final_loss < 0.01` 断言它必须低于 0.01。这是一种"自检"习惯——如果代码改动后这个断言失败，说明改动破坏了训练的某处。

直接运行 `python code/part-1/train_mlp.py` 应当看到 5 行 `step` 日志（步 0 到 800）和 1 行 `final loss`，断言 `final loss < 0.01` 通过、退出码 0。这个例子虽然简单，但已经包含了后续训练 Transformer 所需的全部核心元素：**模型 + 数据 + 损失 + 优化器 + 反向传播**。理解了它，就理解了 Ch4 预训练循环的 80%。

## 本章小结

- 神经元 = 加权求和 + 偏置 + 非线性激活；MLP 是多层神经元堆叠，必须有非线性才能拟合复杂函数。
- 常见激活函数：ReLU（简洁、CNN/MLP 默认）、GELU（平滑、Transformer 默认）、Softmax（多分类输出转概率）。
- 反向传播的核心是链式法则——梯度从损失端反向流回每一层；PyTorch 的 autograd 让这一切自动完成。
- 损失函数：连续值回归用 MSE，离散分类用交叉熵；LLM 训练本质上是 token 级多分类。
- 优化器从 SGD → Adam（自适应学习率）→ AdamW（解耦权重衰减）；Transformer 训练默认用 AdamW。
- 正则化：Dropout 随机失活防结构过拟合，Weight Decay L2 惩罚防参数过大。
- 归一化：BatchNorm 沿 batch 维度（CNN 默认）、LayerNorm 沿特征维度（Transformer 默认）。
