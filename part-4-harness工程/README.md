## 一句话简介

Part 3 讲清了 Agent 由哪些零件组成。Part 4 回答下一个问题：**这些零件装到生产环境里，外面为什么要包一层壳？** 主流 Agent 产品——不管哪个——都长得惊人地相似，不是因为抄袭，而是因为它们都在解同一组工程问题：工具怎么标准化接入、上下文怎么不被撑爆、危险动作怎么拦得住、会话中断了怎么恢复。这一章把这层壳拆成七大职责，再把里面已经标准化的部分（工具协议、Agent 间协作协议）和没标准化的部分（权限、沙箱、钩子）分别讲清楚。
