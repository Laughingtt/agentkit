# 常规稿酬/版税出版 · 完整流程与材料清单

> 适用对象：以个人署名，走"常规稿酬/版税出版" 路线（区别于自费出版）出版一本技术书。
> 本清单以《Agent 原理及实践》这类技术书为例，其余类型的书流程相同、细节略有差异。

---

## 一、两条出版路径先分清

| 维度 | 自费出版 | 常规稿酬/版税出版（本清单） |
|---|---|---|
| 花费 | 约 5–20 万（作者出全资） | 约 0–少量，作者基本不花钱 |
| 收入 | 基本不赚钱 | 按销量拿版税（8%–12%） |
| 目的 | 署名、评职称、独立出版 | 专业背书 + 获利 |
| 周期 | 约 6–12 个月 | 约 12–16 个月（签约→发版） |
| 书号 | 作者自购，出版社配号 | 出版社自有选题立项配号 |

**关键认知**：个人无法直接取得 ISBN，必须由出版社以"正式选题立项"配号。市场上有"低价买号/套号"的灰色渠道，属违规行为（国家明令禁止买卖书号），务必走正规路径。

---

## 二、四大阶段总览

```
壹 投稿与立项签约  →  贰 写作交稿与审校  →  叁 设计排印制  →  肆 发行、结算与发版
```

---

## 三、阶段壹 · 投稿与立项签约（最关键，新手最易懵）

### 1. 准备"选题策划案"（投递敲门砖）
- [ ] **书名方案**：2–3 个备选，正标题 + 副标题
- [ ] **内容简介**：150–300 字，讲清解决什么问题、给谁看
- [ ] **目录大纲**：到"章"或"节"级
- [ ] **样章**：1–2 章完整稿，证明能写、有技术深度
- [ ] **目标读者**：初级读者/一线开发者/企业团队
- [ ] **竞品对比**：同类已出版 Agent 书，你的差异化卖点
- [ ] **作者简介**：技术背景、年限、代表作（GitHub/项目/博客均可）

### 2. 找对出版社和编辑
- 技术书第一梯队：机械工业出版社、人民邮电出版社（图灵/异步社区）、电子工业出版社（博文视点）、清华大学出版社、北京大学出版社
- 渠道：官网"投稿/选题申报"入口、图书版权页责任编辑、技术社区编辑约稿、行业人引荐
- 可**同时多投几家**（签约前不必绑定独家）

### 3. 立项与合同谈判（核心是合同，逐条谈）
- [ ] **结算方式**：版税制（销量×定价×税率）还是稿酬制（按千字一次性）？技术书一般版税制更划算
- [ ] **版税率**：常见 8%–12%，聊清销量阶梯可否上调
- [ ] **结算基数**：按"册数×定价（码洋）"还是"折后实洋"（约定价的 55%–65%）？
- [ ] **结算周期**：季度/半年/年度？多久结一次？
- [ ] **合同期限**：版权授权几年（常见 3–5 年），到期续约还是解约
- [ ] **授权范围**：中文简体纸质为主——电子版、有声、海外/繁体是否一并授权，授权价如何算（新手易忽略白送项）
- [ ] **署名**：第几作者、是否真名；合著时的序位与稿酬分配
- [ ] **交稿义务**：字数、格式、截止日期、逾期责任
- [ ] **违约责任与解约**：违约金、稿子被退回/社方不出版怎么办

---

## 四、阶段贰 · 写作交稿与审校（活儿在你这边）

### 1. 写作期自己的功课
- [ ] 按定稿目录写作，控制总字数与章节节奏
- [ ] **代码必须能在声明版本上跑通**，标注运行环境/依赖版本
- [ ] **配图版权**：框架图、截图、第三方 logo、引用图文，逐项授权或自绘，正文注明出处
- [ ] 术语统一、附录/索引/参考文献整理齐全
- [ ] 提前请圈内人写**推荐语/序言**（大牛背书明显带动销量）

### 2. 交稿与配合修改
- [ ] 按出版社要求交格式（Word / Markdown / LaTeX + 独立图片与代码文件）
- [ ] 应对多轮初审反馈 → 修改 → 复审
- [ ] 三审（初/复/终审）+ 技术外审时，及时回复意见、逐条核改

---

## 五、阶段叁 · 设计排印制

- [ ] **封面设计**：给偏好/元素，定稿权在出版社设计，确认无硬伤
- [ ] **正文与代码排版**：双栏、缩进、断行；核对目录、页眉页脚、脚注、索引
- [ ] **清样/付印样核对**：逐页过，**签字定稿**后即排印
- [ ] 出版社负责申请 **ISBN 与 CIP**，你配合提供作者资料（个人资料、作者简介、身份证信息等）

---

## 六、阶段肆 · 发行、结算与发版

- [ ] **发行**：出版社铺线下渠道 + 电商上架（京东/当当），你可配合推广（讲座、公众号、直播）
- [ ] **样书**：按合同给作者若干册，写进合同
- [ ] **版税结算**：按合同周期核算销量 → 对账 → 结算（注意扣个税）
- [ ] **正式发版**：ISBN 与 CIP 在官方数据库生效、现货开售

---

## 七、新手避坑提醒

1. **合同授权范围是重灾区**：电子版/海外/改编权别稀里糊涂白送，逐条商量价值。
2. **写作周期留缓冲**：技术书常因 API 更新/竞品同质化拖长，deadline 定严但留改稿余量。
3. **别指望出版社帮你卖**：它只负责出版与铺货，**销量主要靠你的技术影响力和推广**——出书更多是"专业背书 + 引流"，直接版税是锦上添花。

---

## 八、周期与收益速查（以《Agent 原理及实践》为例）

### 周期：签约 → 发版 ≈ 12–16 个月

| 环节 | 估算 | 说明 |
|---|---|---|
| 签约/立项 | 1–2 个月 | 热门选题快，也可能卡论证 |
| 写作 | 6–10 个月 | 主投入，Agent 内容要跑通代码、配图 |
| 三审三校 + 外审 | 1.5–3 个月 | 视修改轮数 |
| 排版/封面/书号/CIP | 1.5–3 个月 | ISBN 与 CIP 申报是固定排队 |
| 印刷/质检/上架 | 1–2 个月 | 铺货与上架 |

### 收益：定价 ¥89 × 版税 10% × 按定价计酬（税前毛估）

| 场景 | 销量 | 版税收入 |
|---|---|---|
| 悲观（多数技术书） | 5,000 册 | 约 ¥4.5 万 |
| 基准（Agent 风口） | 1.5 万册 | 约 ¥13 万 |
| 乐观（畅销教程级） | 4 万册 | 约 ¥35 万 |

> 注意：若合同按"实洋"计酬约为上表的 55%–65%；需扣稿酬个税；按合同周期结算"已回款销量"，第一年往往落在较低档，靠重印/加印累积。
