## 一句话简介

Part 4 讲了 Agent 外面那层壳该有哪七大职责，这一章把其中最核心的几项**真正写出来**：模型怎么决定调用哪个工具、检索结果怎么拼进提示词、长期记忆怎么存怎么召回、复杂任务怎么先出计划再执行、多个 Agent 怎么分工与交接、把"执行代码"做成一个工具时该选哪一档隔离，以及怎么手写一个 MCP server / A2A server。

- 不写框架产品教程。主流框架只在"一句话点名 + 抽模式"处出现，用来提炼**框架无关的通用要素**。
